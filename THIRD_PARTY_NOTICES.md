# Watermelon UI

The media card, image overlay card, and pill tab composition in
`app/src/components/WatermelonUI.jsx` are adapted from:

- https://registry.watermelon.sh/r/card-5.json
- https://registry.watermelon.sh/r/card-7.json
- https://registry.watermelon.sh/r/tabs-1.json

Adaptations use local CSS and native React interactions in place of the original
Tailwind and base component dependencies, with Niya content and artwork.
